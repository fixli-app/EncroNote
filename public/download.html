Install on Android

  1. Download the APK on your Android phone.
  2. Open the downloaded file and review Android’s install prompt.
  3. If asked, allow your browser to install apps, then return to the APK.

Android may show a warning because this app is installed directly rather than through Google Play. Only install an APK from the official site you trust.

App security & privacy

Your notes are encrypted on this device with AES-256-GCM. A random data key is encrypted with a key derived from your password using PBKDF2-SHA-256 (600,000 iterations). Only the encrypted key and encrypted vault are stored on this device. Only the encrypted vault is saved in this app’s local storage; there is no account server, database, analytics, or cloud sync.

The app locks after one minute without activity and when it leaves the foreground. Android failed-attempt state is encrypted with an Android Keystore key and synchronously committed before a failed login is reported. A reached limit leaves a secure lockout marker and disables creating a replacement vault. Rooted/jailbroken devices and instrumented app code remain outside this protection. Choose a long, unique password.

This is client-side software, so its published source can be inspected and reverse-engineered. Someone with a copy of the encrypted vault can guess passwords offline; the failed-attempt limit cannot stop that. A compromised phone or altered app can expose notes. No app can guarantee protection from coercion, keyloggers, or every storage copy. Do not rely on this app as the only protection for information whose exposure could put you in danger.

Keep your device updated and use its screen lock. Native vault data is local to this app and does not synchronize.

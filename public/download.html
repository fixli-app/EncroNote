Install on Android

  1. Download the APK on your Android phone.
  2. Open the downloaded file and review Android’s install prompt.
  3. If asked, allow your browser to install apps, then return to the APK.

Android may show a warning because this app is installed directly rather than through Google Play. Only install an APK from the official site you trust.

How your privacy works

The Android app encrypts notes locally and does not send them to this website. The website only distributes the app installer.

Direct downloads need a signed APK. Keep the signing key private and use the same key for future updates. Apps can be reverse-engineered, and no app can guarantee protection on a compromised phone.
